# Credit-Risk-Prediction
Machine Learning project to predict credit default risk using Logistic Regression and Random Forest


# Credit Risk Prediction

This project predicts whether a customer will default on credit payments using Machine Learning.

## 📊 Models Used
- Logistic Regression
- Random Forest

## 📈 Results
- Accuracy: 99%
- ROC-AUC: 1.0

## 🔍 Features
- Exploratory Data Analysis (EDA)
- Feature Scaling
- Model Evaluation
- Feature Importance

## 🛠️ Tools
- Python
- Pandas
- Scikit-learn
- Matplotlib & Seaborn
